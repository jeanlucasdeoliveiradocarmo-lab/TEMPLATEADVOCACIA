# Landing Page de Alta Conversão

Template em Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion e Lucide React.

## Personalização

Todo o conteúdo, identidade, contatos, links, serviços, depoimentos, FAQ e textos legais ficam em `site.config.ts`. Para adaptar o template a outro cliente, altere somente esse arquivo.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm start
```

O projeto pode ser importado diretamente na Vercel sem configuração adicional.
